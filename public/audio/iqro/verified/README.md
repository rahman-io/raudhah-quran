# Iqro vowel recordings

These 81 WAV clips come from respondent 1, repetition 1, in the `Data Benar`
group of Aaz M Hafidz Azis, *Hijaiyah Letter Pronunciation Audio Dataset for
Articulation Characteristic Classification*, Mendeley Data, version 1 (2026),
DOI: https://doi.org/10.17632/r5fy2dd98g.1. Licensed CC BY 4.0:
https://creativecommons.org/licenses/by/4.0/.

Names are `<letter number>-<vowel number>.wav`. Letter numbers follow
`label_per_huruf.csv`; vowel numbers are 1=fathah, 2=kasrah, 3=dammah.
Each clip was peak normalized without changing its timing or pitch. The
original source is `Data Benar/1/<letter>-<vowel>-1.wav`; its decoded float32
PCM MD5 was checked against `metadata_rekaman.csv` before conversion.

Letter 25 (nun) was not copied: the source supplies only `25i`, `25ie`, and
`25ik`, whose context is not documented sufficiently to identify plain nun.
These files are for the Iqro player only. The existing Tajwid recordings are
not modified.
